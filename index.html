Requisitos importantes

Para o APPLoja Desktop funcionar, o computador precisa ter o Microsoft Access e o Microsoft Excel instalados. Os dois programas fazem parte do pacote Microsoft Office.

Microsoft Access Necessário para abrir e executar os recursos do sistema APPLoja Desktop.
Microsoft Excel Necessário para recursos do sistema que utilizam planilhas e exportações.

Não tem Access e Excel instalados?

Use o link abaixo para acessar o arquivo do Microsoft Office 2010 informado para instalação. Se o computador já possui Access e Excel compatíveis, não é necessário instalar o Office novamente.

Abrir download do Office 2010 O Microsoft Office é um produto da Microsoft e deve ser utilizado com uma licença válida.

Como instalar

1 Confirme se o computador possui Microsoft Access e Excel. Caso não possua, instale primeiro o Office.
2 Clique em Baixar APPLoja e abra o arquivo apploja_setup.exe.
3 Siga as etapas apresentadas pelo instalador para concluir a instalação do APPLoja.
Suporte e acesso remoto

Programa para acesso remoto.

O RustDesk é um dos programas utilizados pela equipe APPLoja para acessar o computador do cliente remotamente durante atendimentos de suporte.

Baixar programa de acesso remoto Como utilizar

Arquivo executável para Windows 64 bits. Utilize o acesso remoto somente durante um atendimento autorizado.

RustDesk

Acesso remoto para suporte

Programa de suporte

RustDesk 1.4.9

rustdesk-1.4.9-x86_64.exe Aplicativo de acesso remoto
Windows 64 bits

Como utilizar para suporte

Baixe e abra o programa somente quando precisar de atendimento remoto. A equipe de suporte poderá pedir o identificador e a senha temporária exibidos pelo programa para iniciar o acesso.

1 Clique em Baixar programa de acesso remoto e aguarde o download terminar.
2 Abra o arquivo rustdesk-1.4.9-x86_64.exe no computador que precisa de suporte.
3 Durante o atendimento, informe os dados de acesso exibidos pelo programa somente para a equipe APPLoja responsável pelo suporte.

Importante sobre segurança

Não compartilhe o identificador, senha ou autorização de acesso remoto com pessoas desconhecidas. Encerre a sessão quando o atendimento terminar.
